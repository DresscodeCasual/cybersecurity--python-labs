## 📁 Структура репозиторію

```text
cybersecurity-python-labs/
├── .gitignore          # Правила виключення службових файлів та віртуального середовища
├── README.md           # Документація проекту
├── requirements.txt    # Залежності проекту (Ruff)
├── shared/             # Модулі для спільного використання

    └── lab01/          # Лабораторна робота №1
        ├── __init__.py
        ├── main.py     # Головна точка входу для демонстрації
        ├── task1.py    # Завдання 1: Комплексний аналізатор надійності паролів
        ├── task2.py    # Завдання 2: Багаторівнева система контролю доступу
        ├── task3.py    # Завдання 3: Хешування (SHA3-256), CSV-база та JSON-логування
        └── data/       # Динамічно згенеровані файли
            ├── users.csv
            └── log.json
```

## 🚀 Налаштування та запуск

### 1. Створення та активація віртуального середовища (venv)

```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 3. Перевірка якості коду лінтером Ruff (PEP-8)

```bash
# Статичний аналіз коду
ruff check .

# Автоматичне форматування коду
ruff format .
```

### 4. Запуск лабораторної роботи №1

```bash
# Запуск комплексної демонстрації всіх завдань
python labs/lab01/main.py

# Або запуск окремих завдань:
python labs/lab01/task1.py
python labs/lab01/task2.py
python labs/lab01/task3.py
```

## 📋 Короткий опис завдань (Варіант 13)

1. **Завдання 1:** Аналізатор стійкості паролів за критеріями безпеки (довжина, великі/малі літери, спецсимволи, цифри), виявлення заборонених паролів та імітація повторного використання (дублювання випадкових паролів) із виведенням структурованої таблиці.
2. **Завдання 2:** Система багаторівневого розмежування доступу на основі рівнів допуску (*clearance*) користувачів та категорій безпеки ресурсів (*Open Source*, *Internal Research*, *Proprietary*, *Trade Secret*) з урахуванням статусу активності та блокування.
3. **Завдання 3:** Криптографічне хешування паролів за алгоритмом `sha3_256` із додаванням персональної солі `00013` (мін. довжина 14 символів), збереження бази користувачів у `users.csv`, безпечна автентифікація, логування спроб входу у `log.json` за допомогою декоратора `@log_event` та fail-secure обробка винятків (`ValidationError`, `ValueError`, `OSError`).
