## 🚀 Налаштування та запуск

### 1. Створення та активація віртуального середовища (venv)

```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 3. Перевірка якості коду лінтером Ruff (PEP-8)

```bash
# Статичний аналіз коду всього проєкту
ruff check .

# Перевірка форматування коду
ruff format --check .
```

```bash

python labs/lab02/task1.py
```

## 📌 Короткий опис завдань (Варіант 13)

### Лабораторна робота №1
1. **Завдання 1:** Аналізатор стійкості паролів за критеріями безпеки (довжина, великі/малі літери, спецсимволи, цифри), виявлення заборонених паролів та імітація повторного використання із виведенням структурованої таблиці.
2. **Завдання 2:** Система багаторівневого розмежування доступу на основі рівнів допуску (*clearance*) користувачів та категорій безпеки ресурсів (*Open Source*, *Internal Research*, *Proprietary*, *Trade Secret*) з урахуванням статусу активності та блокування.
3. **Завдання 3:** Криптографічне хешування паролів за алгоритмом `sha3_256` із додаванням персональної солі `00013` (мін. довжина 14 символів), збереження бази користувачів у `users.csv`, безпечна автентифікація, логування спроб входу у `log.json` за допомогою декоратора `@log_event` та fail-secure обробка винятків.

### Лабораторна робота №2
1. **Завдання 1:** Об'єктно-орієнтована модель облікового запису користувача (`User`, `Admin`, `Session`, `AuditLog`, `UserAccount`):
   - Хешування паролів через PBKDF2-HMAC-SHA256 з персональною сіллю та `hmac.compare_digest`.
   - Валідація email за допомогою `@property` та регулярного виразу `re`.
   - Наслідування: клас `Admin` з керуванням набором дозволів.
   - Сесії в UTC з контролем таймауту неактивності (`is_active`).
   - Журнал аудиту `AuditLog` із незмінними записами `@dataclass` `AuditRecord`.
   - Композиція в `UserAccount` та магічні методи `__getitem__` / `__setitem__` з валідацією типів і захистом секретів.
2. **Завдання 2:** Консольна CLI-утиліта «Сканер витоків конфіденційних даних» (*PII Exfiltration Scanner*):
   - Рекурсивне сканування каталогів за допомогою `pathlib.Path`.
   - Детектування email-адрес, номерів кредитних карток, номерів телефонів та IPv4-адрес за допомогою регулярних виразів `re`.
   - Маскування знайдених чутливих даних для безпечного виведення та експорту (`--mask`).
   - Агрегація статистики за типами за допомогою `collections.Counter`.
   - Логування через `logging` (`logger.warning` при знаходженні відкритих PII) та експорт санітизованого аудиторського звіту в JSON (`--out-json`).
